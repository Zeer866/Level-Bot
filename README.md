# Level Bot (Geode, Android)

Mod de Geode que genera niveles automaticamente y los sube a tu GDPS.

## Instalar (Android)
1. Compila con GitHub Actions (pestana Actions > Build Level Bot > Run workflow).
2. Descarga el artefacto "Build Output" y saca el archivo `.geode`.
3. Copialo a la carpeta `geode/mods` de tu Geometry Dash.

## Uso
1. Inicia sesion en tu cuenta del GDPS.
2. Menu principal > boton **Bot**.
3. Escribe la cantidad (1 a 1000) y pulsa **Iniciar**. No cierres el popup mientras sube.
4. Ajustes del mod: segundos entre subidas y objetos por nivel.
